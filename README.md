# CodeAlpha Data Analytics Internship

This repository contains two Data Analytics projects completed as part of the CodeAlpha Internship.

## Task 2: Exploratory Data Analysis (EDA)
- Analyzed the Students Performance dataset.
- Checked missing values and duplicate records.
- Studied average marks by gender and test preparation.
- Analyzed correlations between subjects.
- Exported analysis results as CSV files.

## Task 3: Data Visualization
- Created charts using Python, Pandas, Matplotlib and Seaborn.
- Visualized average subject scores.
- Compared student performance by gender.
- Compared test preparation and student performance.
- Created a subject correlation heatmap.

## Dataset
Students Performance Dataset (1000 student records).

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
